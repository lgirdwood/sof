# Daily Status Tracking (status.md)

As an agent working in this repository, you must maintain and update the `status.md` file located in the root of the workspace.

## Location
- The file is located at the workspace root directory: `status.md` (e.g. `../status.md` if your current directory is the inner `sof` subdirectory, or `./status.md` if at the top-level workspace root).

## Guidelines for Updating `status.md`
1. **When to Update**:
   - **At the start of a task**: Mark the relevant task as in-progress `[/]`, or add/update the goal description.
   - **During the task**: Keep the status file updated with any findings, blockers, or progress.
   - **At the end of your session/task**: Check off completed items `[x]`, list any pending items, and add notes/context for the next session or the developer.
2. **File Structure**:
   Maintain the existing structure:
   - **Topic**: Summary of the branch topic.
   - **Today's Focus**: Checklist of tasks. Mark tasks as completed `[x]`, in-progress `[/]`, or uncompleted `[ ]`.
   - **Context & Agent Instructions**: Freeform notes on details, designs, or blocker contexts.
   - **References**: Associated PRs, issues, or ticket numbers.
3. **Be Specific**:
   - Keep notes concise and actionable.
   - Always link or reference modified files or relevant PRs.
